В этом репозитории есть 2 небольших приложения, использующих JS и HTML. 

Первое приложение (App1) представляет из себя список из двух элементов, названия которых можно менять. Если текстовое поле пустое, или в нём одни пробелы, то оно загорается красным.
При переименовании все ненужные пробелы убираются, в названии не может быть 2 пробела подряд, если  названии проел - первый символ, то он тоже убиается.

Второе приложение (App2) чуть сложнее первого. Он является реализацией простого ToDo листа, где можно добавлять новые задачи со своими названиями. 
Сама задача имеет 2 статуса: "в процессе" и "выполнено". 
Отображение задач имеет 3 режима: Показывать всё, Показывать в процессе и Показывать выполненные. 
Имеется кнопка "Удалить всё", которая удаляет все созданные задачи. 
Данное приложение работает только на Mozilla и подобных ему браузерах. 
Это связанно с особенностями языка Common JS.
